# Decision records — index

Choices about these conventions that would be expensive to reverse and confusing to rediscover. The bar, the format and the numbering rule are in [Architecture decisions](../decisions.md); this file is the registry.

**One row per record, added in the same change as the record.** An index that lags is worse than no index, because it is trusted.
